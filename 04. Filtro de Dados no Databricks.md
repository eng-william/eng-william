## 1. Introdução

Filtrar dados é uma das operações mais frequentes em pipelines e análises. No Databricks, com **PySpark**, você pode:

- Usar **filter()** ou **where()** no DataFrame (são equivalentes).
- Combinar várias condições com operadores lógicos **&** (E) e **|** (OU).
- Aplicar **funções** (ex.: `lower`, `trim`) para normalizar texto antes de comparar.
- Usar **SQL** após registrar o DataFrame como vista temporária.

Este material organiza as formas de filtrar no Spark para servir como **referência de consulta** nos seus projetos.

---

## 2. filter() e where() — mesma função

No PySpark, **filter** e **where** fazem a mesma coisa. Use o que for mais legível no seu código.

```python
# Os dois retornam o mesmo resultado
df.filter(df.estado == "SP")
df.where(df.estado == "SP")
```

A sintaxe é: `df.filter(condição)` ou `df.where(condição)`. A condição pode usar o nome da coluna com `df.nome_coluna` ou a função `col("nome_coluna")` (veja seção 7).

---

## 3. Filtro com um critério

**Igualdade:** para strings, use aspas simples ou duplas no valor.

```python
# Visualizar sem salvar
display(df.filter(df.estado == "MG"))

# Salvar em um novo DataFrame
df_mg = df.filter(df.estado == "MG")
display(df_mg)

# Sobrescrever o DataFrame original (cuidado: perde o restante dos dados)
df = df.filter(df.estado == "MG")
display(df)
```

**Diferente:** use `!=`.

```python
display(df.filter(df.estado != "MG"))
```

---

## 4. Vários critérios — operadores lógicos

Para combinar condições, use **parênteses** em cada condição e o operador no meio:

| Operador | Significado | Exemplo |
|----------|-------------|---------|
| `&` | E (ambas as condições) | `(df.estado == "MG") & (df.categoria == "Ativo")` |
| &#124; | OU (pelo menos uma) | `(df.estado == "MG") \| (df.estado == "SP")` |
| `~` | NÃO (negação) | `~(df.estado == "MG")` |

**E lógico (&):** o registro só entra se atender **todas** as condições.

```python
display(
    df.filter((df.estado == "MG") & (df.categoria == "Incidente"))
)
```

**OU lógico (|):** o registro entra se atender **qualquer** condição.

```python
display(
    df.filter((df.nivel == "Leve") | (df.categoria == "Incidente"))
)
```

**Salvando o resultado em um novo DataFrame:**

```python
df_filtrado = df.filter(
    (df.nivel != "Leve") & (df.categoria == "Incidente")
)
display(df_filtrado)
```

**Boa prática:** sempre coloque cada condição entre parênteses quando usar `&` ou `|`, para evitar erro de precedência de operadores.

## 5. Resultado: visualizar, novo DataFrame ou sobrescrever

| Objetivo | Código |
|----------|--------|
| Só visualizar | `display(df.filter(...))` |
| Novo DataFrame | `df_novo = df.filter(...)` |
| Sobrescrever o DataFrame | `df = df.filter(...)` |

Sobrescrever o `df` original é útil quando você não precisa mais dos dados completos; caso contrário, prefira criar um novo DataFrame para não perder o conjunto original.

## 6. Filtros via SQL

Se você prefere escrever a lógica em SQL, registre o DataFrame como **view temporária** e use `spark.sql()`.

```python
# Criar vista temporária (visível só nesta sessão)
df.createOrReplaceTempView("minha_tabela")

# Consulta com WHERE
resultado = spark.sql("""
    SELECT
        categoria AS tipo,
        fase,
        municipio,
        estado
    FROM minha_tabela
    WHERE estado = 'MG'
      AND fase = 'Decolagem'
""")
display(resultado)
```

Versão em uma linha:

```python
resultado = spark.sql("SELECT * FROM minha_tabela WHERE estado = 'MG'")
display(resultado)
```

Para remover a view ao final (opcional):

```sql
-- Em célula SQL
DROP TABLE IF EXISTS minha_tabela;
```

## 7. Usando col() e filtros dinâmicos

Importar **col** de `pyspark.sql.functions` permite referenciar a coluna pelo nome em string, o que facilita filtros **dinâmicos** (nome da coluna ou valor em variáveis).

```python
from pyspark.sql.functions import col

# Filtro com col()
display(df.filter(col("estado") == "SP"))
```

**Filtro dinâmico:** coluna e valor em variáveis (útil em notebooks parametrizados ou loops):

```python
coluna = "estado"
valor = "MG"
display(df.filter(df[coluna] == valor))

# Dois critérios dinâmicos
coluna1, filtro1 = "estado", "MG"
coluna2, filtro2 = "categoria", "Incidente"
display(
    df.filter((df[coluna1] == filtro1) & (df[coluna2] == filtro2))
)
```

## 8. Filtro por índice da coluna

Quando você tem muitas colunas e quer filtrar pela posição (índice), use `df.columns[índice]`:

```python
# Descobrir o índice de uma coluna
nome_coluna = "operador"
indice = df.columns.index(nome_coluna)
print(indice)  # ex.: 43

# Filtrar pela coluna no índice 43
df_filtrado = df.filter(col(df.columns[43]) == "XYZ")
display(df_filtrado)
```

**Tabela de referência (coluna × índice):** útil em DataFrames com dezenas de colunas.

```python
lista_indices = [(c, df.columns.index(c)) for c in df.columns]
df_indices = spark.createDataFrame(lista_indices, ["coluna", "indice"])
display(df_indices)
```

**Tabela de referência com nome, índice e tipo de dado:** percorre todas as colunas e monta um DataFrame de metadados (nome da coluna, índice e tipo).

```python
# Lista para inserir os dados
lista_colunas_info = []

# Loop para identificar o índice, nome das colunas e tipos dos dados
for indice, (nome_coluna, tipo_dado) in enumerate(df.dtypes):
    lista_colunas_info.append((nome_coluna, indice, tipo_dado))

# Salvar a lista no novo DataFrame
df_metadados = spark.createDataFrame(lista_colunas_info, ["COLUNA", "INDICE", "TIPO"])

# Exibir o resultado
display(df_metadados)
```

## 9. Filtros numéricos e intervalos

Operadores usuais: `==`, `!=`, `<`, `>`, `<=`, `>=`.

```python
# Status igual a 1 (ex.: pedidos pendentes)
pedidos_pendentes = df.filter(df.status == 1)
display(pedidos_pendentes)

# Loja diferente de 3
fora_loja_3 = df.filter(df.loja_id != 3)
display(fora_loja_3)

# Preço menor que 300
baratos = df.filter(df.preco < 300)
display(baratos)

# Preço maior que 2000
caros = df.filter(df.preco > 2000)
display(caros)

# Intervalo: entre 700 e 1200 (inclusive)
medio = df.filter((df.preco >= 700) & (df.preco <= 1200))
display(medio)
```

**Alternativa para intervalo: between()**

```python
medio = df.filter(col("preco").between(700, 1200))
display(medio)
```

## 10. Padrões de texto: like

Para buscar textos que **contêm**, **começam** ou **terminam** com um trecho, use **like** com curingas:

- **%** — qualquer sequência de caracteres (inclusive vazia).
- **_** — um único caractere.

```python
# Descricao termina com "AVE"
resultado = df.filter(df.descricao_tipo.like("%AVE"))
display(resultado)

# Nome começa com "São"
resultado = df.filter(df.nome.like("São%"))

# Nome contém "Silva"
resultado = df.filter(df.nome.like("%Silva%"))
```

**Observação:** `like` no Spark é sensível a maiúsculas/minúsculas. Para ignorar isso, use `lower()` na coluna e no padrão (veja seção 12).

## 11. Valores em lista: isin()

Quando o filtro é “coluna igual a um destes valores”, **isin()** deixa o código mais limpo que vários `|`.

```python
# Estado é MG, SP ou RJ
df_estados = df.filter(df.estado.isin("MG", "SP", "RJ"))
display(df_estados)

# Usando uma lista
estados_selecionados = ["MG", "SP", "RJ"]
df_estados = df.filter(df.estado.isin(*estados_selecionados))
display(df_estados)
```

**Negar isin:** registros cujo valor **não** está na lista:

```python
df_outros = df.filter(~df.estado.isin("MG", "SP"))
display(df_outros)
```

## 12. Tratamento de texto antes de filtrar

Dados reais costumam ter diferenças de **maiúsculas/minúsculas** e **espaços** em branco. Aplicar funções antes de comparar evita filtros vazios.

### 12.1. Case (maiúsculas/minúsculas)

Use **lower()** ou **upper()** na coluna e compare com o valor no mesmo padrão:

```python
from pyspark.sql.functions import lower, upper

# Valores distintos da coluna (para inspecionar)
display(df.select(lower("fase")).distinct())
display(df.select(upper("fase")).distinct())

# Filtro insensível a maiúsculas/minúsculas
display(df.filter(lower(df.fase) == "decolagem"))
```

### 12.2. Espaços em branco: trim, ltrim, rtrim

**trim** remove espaços no início e no fim; **ltrim** só no início; **rtrim** só no fim.

```python
from pyspark.sql.functions import trim, ltrim, rtrim

# Comparar após remover espaços das pontas
display(df.filter(trim(df.cidade) == "Belo Horizonte"))

# Só início
display(df.filter(ltrim(df.cidade) == "Belo Horizonte"))

# Trim + lower juntos
display(df.filter(lower(trim(df.cidade)) == "belo horizonte"))
```

Assim você não depende de como o dado foi digitado (com espaços ou variação de caixa).

---

## 13. Valores nulos: isNull e isNotNull

Para filtrar por ausência ou presença de valor:

```python
# Coluna é nula
df_nulos = df.filter(col("telefone").isNull())
display(df_nulos)

# Coluna não é nula
df_preenchidos = df.filter(col("telefone").isNotNull())
display(df_preenchidos)
```

**Cuidado:** em comparações com `==`, o resultado de `coluna == None` pode não se comportar como esperado; use **isNull()** para nulos.

## 14. Resumo rápido

| Situação | Exemplo |
|----------|---------|
| Um critério (igual) | `df.filter(df.estado == "MG")` |
| Um critério (diferente) | `df.filter(df.estado != "MG")` |
| E lógico | `df.filter((df.estado == "MG") & (df.categoria == "Ativo"))` |
| OU lógico | `df.filter((df.estado == "MG") \| (df.estado == "SP"))` |
| Com col() | `df.filter(col("estado") == "SP")` |
| Dinâmico | `df.filter(df[coluna] == valor)` |
| Número em intervalo | `df.filter(col("preco").between(100, 500))` |
| Texto com padrão | `df.filter(df.nome.like("%Silva%"))` |
| Valor em lista | `df.filter(df.estado.isin("MG", "SP", "RJ"))` |
| Case insensível | `df.filter(lower(df.cidade) == "belo horizonte")` |
| Com trim | `df.filter(trim(df.cidade) == "Belo Horizonte")` |
| Nulos | `df.filter(col("telefone").isNull())` |
| Não nulos | `df.filter(col("telefone").isNotNull())` |

**Dica:** use parênteses em cada condição ao combinar `&` e `|`, e prefira `col()` quando o nome da coluna vier de variável ou quando quiser código mais uniforme.
