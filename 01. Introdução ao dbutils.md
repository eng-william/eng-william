## 1. O que é o dbutils?

O **dbutils** (Databricks Utilities) é um conjunto de utilitários nativos do Databricks que permite interagir com o ambiente de forma prática a partir de notebooks e jobs. Ele não precisa ser importado: já está disponível em qualquer sessão do Databricks.

Com o dbutils você pode, entre outras coisas:

- **Manipular arquivos** no DBFS (sistema de arquivos do Databricks)
- **Trabalhar com widgets** (parâmetros interativos nos notebooks)
- **Acessar secrets** (credenciais armazenadas de forma segura)
- **Controlar notebooks** (executar outros notebooks, passar parâmetros)

Neste material o foco é no uso do **dbutils para manipulação de arquivos**, que é uma das partes mais usadas no dia a dia com Databricks.

---

## 2. DBFS: o sistema de arquivos do Databricks

O **DBFS** (Databricks File System) é o sistema de arquivos distribuído do Databricks. Os arquivos que você envia pela interface (por exemplo, em **Data** → **Add Data** → **Upload File**) ou que são gravados pelos seus jobs ficam armazenados no DBFS.

Alguns caminhos importantes:

| Caminho | Descrição |
|--------|-----------|
| `/` | Raiz do DBFS |
| `/FileStore/` | Arquivos enviados pela interface (uploads) |
| `/FileStore/tables/` | Local comum para tabelas/CSVs usados em notebooks |
| `/databricks-datasets/` | Conjuntos de dados de exemplo fornecidos pelo Databricks |
| `/databricks-results/` | Resultados de queries e exportações |

Todo comando do **dbutils.fs** atua sobre caminhos no DBFS (ou em sistemas montados, como Azure Data Lake, S3, etc.).

## 3. Como descobrir os comandos disponíveis

No Databricks você pode consultar a ajuda diretamente no notebook:

```python
# Lista todos os módulos do dbutils (fs, notebook, widgets, secrets, etc.)
dbutils.help()
```

```python
# Lista todos os comandos do dbutils.fs (sistema de arquivos)
dbutils.fs.help()
```

Use esses comandos sempre que quiser relembrar a assinatura e a descrição de cada função.

## 4. dbutils.fs — comandos de sistema de arquivos

### 4.1. ls — listar diretórios

Lista o conteúdo de um diretório no DBFS. Retorna uma lista de objetos com informações como nome, caminho, tamanho e data de modificação.

**Sintaxe:** `dbutils.fs.ls(caminho)`

**Exemplos no Databricks:**

```python
# Listar a raiz do DBFS
dbutils.fs.ls('/')

# Listar arquivos na pasta padrão de tabelas (onde costumam ficar os CSVs)
dbutils.fs.ls('/FileStore/tables')

# Exibir em formato de tabela (mais legível no notebook)
display(dbutils.fs.ls('/FileStore/tables'))

# Listar datasets de exemplo do Databricks
dbutils.fs.ls('/databricks-datasets')

# Listar dentro de uma subpasta (ex.: Bikes)
display(dbutils.fs.ls('/FileStore/tables/Bikes'))
```

---

### 4.2. head — visualizar início de arquivos

Retorna os primeiros bytes de um arquivo como string (UTF-8). Útil para inspecionar rapidamente um CSV ou arquivo de texto sem carregar tudo no Spark.

**Sintaxe:** `dbutils.fs.head(caminho_arquivo, maxBytes=65536)`

- **maxBytes** (opcional): quantidade máxima de bytes a ler (padrão: 65536).

**Exemplo no Databricks:**

```python
# Ver o início do arquivo Clientes.csv (primeiros ~65 KB)
dbutils.fs.head('/FileStore/tables/Clientes.csv')

# Ver apenas os primeiros 500 bytes
dbutils.fs.head('/FileStore/tables/Clientes.csv', maxBytes=500)
```

---

### 4.3. mkdirs — criar diretórios

Cria um diretório no DBFS. Se os diretórios pais não existirem, eles também são criados (equivalente a `mkdir -p` no Linux).

**Sintaxe:** `dbutils.fs.mkdirs(caminho_diretorio)`

**Exemplos no Databricks:**

```python
# Criar pasta Bikes dentro de FileStore/tables
dbutils.fs.mkdirs('/FileStore/tables/Bikes')

# Criar estrutura de pastas (todas as pastas intermediárias são criadas)
dbutils.fs.mkdirs('/FileStore/tables/Projeto/raw/2024')

# Verificar se a pasta foi criada
display(dbutils.fs.ls('/FileStore/tables/Bikes'))
```

---

### 4.4. rm — remover arquivos ou pastas

Remove um arquivo ou diretório do DBFS.

**Sintaxe:** `dbutils.fs.rm(caminho, recurse=False)`

- **recurse** (opcional): se `True`, remove o diretório e todo o seu conteúdo. Para pastas, é necessário usar `recurse=True`.

**Exemplos no Databricks:**

```python
# Remover um único arquivo
dbutils.fs.rm('/FileStore/categories.csv')

# Remover vários arquivos usando um loop (organização de arquivos no lugar errado)
excluir = [
    "/FileStore/categories.csv",
    "/FileStore/customers.csv",
    "/FileStore/orders.csv",
]
for arquivo in excluir:
    dbutils.fs.rm(arquivo)

# Remover uma pasta e todo o seu conteúdo
dbutils.fs.rm('dbfs:/FileStore/tables/Bikes2/', recurse=True)
```

---

### 4.5. cp — copiar arquivos ou pastas

Copia um arquivo ou diretório para outro local, podendo ser entre diferentes sistemas de arquivos (ex.: DBFS para um mount).

**Sintaxe:** `dbutils.fs.cp(origem, destino, recurse=False)`

- **recurse**: se `True`, copia todo o conteúdo do diretório recursivamente.

**Exemplos no Databricks:**

```python
# Copiar um único arquivo
dbutils.fs.cp('/FileStore/tables/Clientes.csv', '/FileStore/tables/backup/Clientes.csv')

# Copiar uma pasta inteira (com todo o conteúdo)
dbutils.fs.cp('/FileStore/tables/Bikes', '/FileStore/tables/Bikes_backup', recurse=True)
```

---

### 4.6. mv — mover ou renomear

Move um arquivo ou diretório para outro caminho. Também serve para renomear (mover para o mesmo diretório com outro nome).

**Sintaxe:** `dbutils.fs.mv(origem, destino, recurse=False)`

**Exemplos no Databricks:**

```python
# Mover um arquivo para outra pasta
dbutils.fs.mv('/FileStore/arquivo.csv', '/FileStore/tables/Projeto/arquivo.csv')

# Renomear uma pasta (mover para novo nome)
# recurse=True para mover tudo que estiver dentro da pasta
dbutils.fs.mv('/FileStore/tables/Anac/V_OCORRENCIA_AMPLA-zip', '/FileStore/tables/Anac/csv_zip', recurse=True)
```

---

### 4.7. put — gravar conteúdo em arquivo

Grava uma string em um arquivo no DBFS (codificação UTF-8). Útil para criar arquivos de configuração, pequenos textos ou scripts diretamente pelo notebook.

**Sintaxe:** `dbutils.fs.put(caminho_arquivo, conteudo, overwrite=False)`

- **overwrite**: se `True`, sobrescreve o arquivo caso já exista.

**Exemplo no Databricks:**

```python
# Criar um arquivo de texto com conteúdo simples
dbutils.fs.put('/FileStore/tables/config.txt', 'versao=1.0\nambiente=producao', overwrite=True)

# Ver o que foi gravado
dbutils.fs.head('/FileStore/tables/config.txt')
```

## 5. Outros módulos do dbutils

Além do **dbutils.fs**, o dbutils oferece outros módulos úteis:

| Módulo | Uso principal |
|--------|----------------|
| **dbutils.notebook** | Executar outro notebook (`run`), sair com valor (`exit`) |
| **dbutils.widgets** | Criar e ler parâmetros (dropdown, text, etc.) nos notebooks |
| **dbutils.secrets** | Acessar secrets (credenciais) armazenados no Databricks |
| **dbutils.library** | Gerenciar bibliotecas (instalar, atualizar) |

Para ver a lista completa e a ajuda de cada um, use `dbutils.help()` no notebook.

## 6. Caminhos no Databricks

No Databricks você pode usar os caminhos de duas formas equivalentes no DBFS:

- **Sem prefixo:** `/FileStore/tables/Clientes.csv`
- **Com prefixo:** `dbfs:/FileStore/tables/Clientes.csv`

Ao ler com **Spark** (por exemplo, `spark.read.csv`), ambos funcionam:

```python
# Ambas as formas são válidas
spark.read.csv("/FileStore/tables/Bikes/customers.csv", header=True, inferSchema=True)
spark.read.csv("dbfs:/FileStore/tables/Bikes/customers.csv", header=True, inferSchema=True)
```

O caminho com **/dbfs/** (por exemplo `/dbfs/FileStore/tables/Clientes.csv`) é usado quando você acessa o arquivo como **arquivo local** (filesystem da máquina driver), não pelo dbutils.fs. No dbutils.fs use `/` ou `dbfs:/`.
