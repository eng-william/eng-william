# 🧱 Tipos de Nós no n8n

O **n8n** permite criar automações conectando blocos chamados **nós** (*nodes*), que executam ações, tomam decisões, manipulam dados ou controlam o fluxo de execução.

Nesta documentação, você encontrará uma explicação detalhada sobre cada **tipo de nó**, exemplos práticos e como eles se encaixam nos fluxos de trabalho.

## 🔹 1. Gatilhos (Trigger Nodes)

Esses nós iniciam a execução de um fluxo de trabalho com base em **eventos** internos ou externos.

### Exemplos:
- **Webhook Trigger** 🌐: Inicia o fluxo ao receber uma requisição HTTP.
- **Cron Trigger** ⏰: Executa o fluxo em intervalos regulares (diário, semanal, etc.).
- **Email Trigger** 📥: Dispara quando um e-mail é recebido.
- **Google Sheets Trigger** 📊: Detecta alterações em uma planilha.

> 💡 Dica: Um fluxo pode ter múltiplos gatilhos, mas apenas um será executado por vez.

---

## 🔹 2. Ações (Action Nodes)

Executam **tarefas específicas**, geralmente interagindo com serviços externos ou executando ações como enviar e-mails ou fazer requisições HTTP.

### Exemplos:
- **HTTP Request** 🌍: Faz chamadas REST (GET, POST, etc.).
- **Send Email** 📬: Envia e-mails com conteúdo dinâmico.
- **Slack** 💬: Envia mensagens para canais ou DMs.
- **Airtable** 📋: Cria, lê ou edita registros em bancos de dados Airtable.

> ⚙️ São os nós que "fazem algo" após os dados serem recebidos ou processados.

---

## 🔹 3. Lógica (Logic Nodes)

Adicionam **inteligência** e **decisão condicional** ao fluxo.

### Exemplos:
- **IF** 🔀: Avalia uma condição e escolhe entre "verdadeiro" ou "falso".
- **Switch** 🎚️: Permite múltiplos caminhos com base em um valor.
- **Merge** 🔗: Junta dados de dois ou mais nós.
- **Set** ✍️: Cria ou modifica campos no dado atual (sem usar código).

> 🧠 Úteis para adaptar o fluxo com base nos dados ou em regras de negócio.

---

## 🔹 4. Controle de Fluxo (Flow Control Nodes)

Gerenciam **como e quando** os nós são executados. Permitem **loops**, **esperas** e **chamadas de outros fluxos**.

### Exemplos:
- **Wait** ⏸️: Pausa a execução até que um tempo ou condição seja atendido.
- **Execute Workflow** 📂: Chama outro fluxo de trabalho como subfluxo.
- **SplitInBatches** ➗: Divide dados em partes menores para processar em lotes.

> 🔄 Muito úteis em integrações com APIs com limites ou processos assíncronos.

---

## 🔹 5. Manipulação de Dados (Data Transformation Nodes)

Permitem transformar, formatar ou criar dados **dentro do fluxo**, sem depender de serviços externos.

### Exemplos:
- **Function** 🧮: Permite escrever código JavaScript simples.
- **Code** 💻: Versão mais moderna do Function Node, com recursos atualizados.
- **Set / Move / Rename Keys** 🔤: Manipulam campos diretamente.
- **Spreadsheet File** 📄: Lê ou escreve arquivos `.csv` e `.xlsx`.

> 🛠️ Úteis para tratar dados entre APIs, validar entradas ou gerar relatórios.

---

## 🔹 6. Nós Específicos de Serviços

Esses nós são **pré-configurados para integrar com APIs conhecidas** como:

- **Google Sheets** 📊
- **Trello** 📌
- **Notion** 🧾
- **GitHub** 🐙
- **Telegram** 💬
- **MySQL / PostgreSQL** 🛢️

Cada serviço oferece ações específicas (como "create card", "get record", etc.), que variam conforme a API.

> 🧩 O n8n oferece **centenas de integrações prontas**, e ainda permite criar integrações personalizadas via HTTP ou código.

---

## 📌 Considerações Finais

Os nós do n8n são como peças de LEGO: quanto mais você entende as possibilidades de cada um, mais poderosas suas automações se tornam.

> 📦 Combine gatilhos, lógica, ações e transformações para construir automações robustas, escaláveis e reutilizáveis.
