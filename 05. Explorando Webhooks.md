## 📌 O que é um Webhook?

Um **Webhook** é uma maneira de um sistema enviar dados automaticamente para outro sistema, **em tempo real**, quando um determinado evento acontece.

> 📬 Pense no Webhook como uma “notificação push” entre sistemas.  
> Em vez de você perguntar todo minuto “tem algo novo?”, o outro sistema te avisa assim que algo acontece.

---

## 🔁 Webhook vs API tradicional

| API Tradicional (Polling)          | Webhook (Event-driven)            |
|------------------------------------|-----------------------------------|
| Você pergunta várias vezes         | Você é avisado automaticamente    |
| Consome mais recursos              | Mais leve e eficiente             |
| Pode ter atraso nas atualizações   | Resposta em tempo real            |
| Ideal para controle e agendamento | Ideal para reatividade            |

---

## 💡 Casos de uso práticos

- 📦 **E-commerce**: Receber pedidos em tempo real.
- 💳 **Pagamentos**: Detectar quando um pagamento é aprovado.
- 📧 **E-mail marketing**: Saber quando alguém clica ou abre uma campanha.
- 🤖 **Chatbots**: Responder mensagens em tempo real.
- 📂 **Formulários**: Receber respostas automaticamente.

---

## ⚙️ Como funciona um Webhook

1. Você fornece uma **URL pública** (ex: `https://minha-api.com/webhook`).
2. O sistema externo envia uma **requisição HTTP POST** com os dados para essa URL assim que o evento ocorre.
3. O seu sistema (n8n) **recebe e processa os dados** imediatamente.

---

## 🧰 Criando um Webhook no n8n

1. **Adicione o nó "Webhook"** no seu fluxo.
2. Escolha o **método HTTP** (geralmente `POST`).
3. Defina o **caminho do webhook** (ex: `/novo-pedido`).
4. Conecte esse nó aos próximos passos (ex: salvar em planilha, enviar e-mail).
5. **Ative o workflow** para que o webhook fique escutando.

> ⚠️ Durante o desenvolvimento, o n8n precisa estar em execução para capturar os dados. Após publicar o fluxo, ele fica permanentemente escutando.

---

## 🧪 Testando seu Webhook

Você pode testar o webhook de duas formas:

### 1. Manual (via ferramenta)
- Use ferramentas como [Postman](https://www.postman.com/) ou [Webhook.site](https://webhook.site/) para enviar uma requisição `POST` para a URL do seu webhook.
- Verifique se o n8n recebeu e processou a requisição.

### 2. Real (via integração)
- Configure um serviço real (ex: Stripe, Typeform) para enviar notificações para o webhook do seu n8n.

## 📥 Exemplo prático: Recebendo dados do Typeform

### 🎯 Objetivo:
Salvar automaticamente as respostas de um formulário Typeform em uma planilha.

### 🛠 Passo a passo:

1. **No n8n**:
   - Adicione um **nó Webhook** (`POST`, caminho `/resposta-typeform`).
   - Conecte a um nó como **Google Sheets** ou **Email**.
   - Ative o workflow.

2. **No Typeform**:
   - Acesse o painel de integrações.
   - Adicione um webhook apontando para a URL gerada pelo n8n (ex: `https://seu-n8n.com/webhook/resposta-typeform`).

3. **Resultado**:
   Sempre que alguém preencher o formulário, os dados chegarão no n8n em tempo real e serão processados automaticamente.

---

## 🧠 Boas práticas

- ✅ Valide os dados recebidos antes de processar.
- ✅ Use autenticação no webhook se possível (token, assinatura).
- ✅ Mantenha logs de eventos recebidos.
- ⚠️ Nunca deixe webhooks abertos publicamente sem proteção.

---

## ✅ Conclusão

- Webhooks são **gatilhos automáticos** que ajudam seu fluxo a responder a eventos externos em tempo real.
- No **n8n**, é muito simples criar e utilizar Webhooks, tornando suas automações ainda mais poderosas.
- Use Webhooks sempre que precisar reagir a um evento externo sem depender de verificações constantes (polling).

---

✨ **Resumo:**  
Com Webhooks e o poder do n8n, suas automações passam a ser **proativas**, **eficientes** e **instantâneas**, reagindo a eventos à medida que acontecem — sem atrasos e sem desperdício de recursos.
